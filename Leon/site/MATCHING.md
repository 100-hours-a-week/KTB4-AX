# PAIR · 카테부 모의면접 매칭

1~20팀 선택 → 본인 이름 선택 → 매칭 시작 순서로 사용합니다. 부서는 엑셀 명단에서 자동 설정됩니다. 명단 선택은 신원 인증이 아니며, 기존 브라우저 세션 방식을 유지합니다.

## 이번 업데이트

- 최신 `team_seating_chart_names_revised (1).xlsx`의 `명단!A2:F115`에서 20팀 114명을 추출했습니다. 영어 이름은 점 앞의 닉네임만 표시합니다. 수정된 belle, dice, hennie, emet을 반영하고 기존 브라우저 세션도 새 ID로 연결합니다. 14팀은 김민지·김태남·백승환·박소현·박윤혁입니다. 박윤혁은 엑셀 기준 풀스택입니다.
- 오늘 건수는 한국 시간 기준으로 연결된 한 쌍을 1건으로 셉니다. 면접 완료 횟수와 다르며, 이 업데이트 이전 매칭은 복원할 수 없어 포함하지 않습니다. 신청 기록이 만료되어도 익명 일별 합계는 유지됩니다.
- 대기 중 방향키·스와이프·방향 버튼으로 지렁이 게임을 합니다. 화면 끝을 통과하면 반대쪽에서 이어서 움직입니다. 자기 몸이나 꼬리에 닿으면 종료합니다. 오른쪽 아래 숫자는 대기 시간(초)이고, 매칭되면 연결에 걸린 시간이 고정됩니다. 게임을 하지 않거나 충돌해도 매칭 대기는 계속됩니다.
- ‘제가 갈게요’는 상대를 ‘제가 기다릴게요’로 설정합니다. 반대 선택도 양쪽에 함께 적용되며, 마지막 선택이 우선합니다. 전체 자리표는 한 화면에서 내 자리와 파트너 자리만 구분하며 가로 스크롤이나 목적지 선택은 없습니다. 자리 번호와 집계 보조 문구는 제거했습니다. 새 매칭에서는 이전 선택을 초기화합니다.
- 크롬 알림은 ‘매칭 완료 시 크롬 알림 받기’에서 허용합니다. HTTPS와 알림 허용이 필요하며 이 페이지를 열어둬야 합니다. 닫힌 페이지에는 푸시를 보내지 않습니다. OS의 방해금지·알림 설정에 따라 팝업이 숨겨질 수 있습니다.
- 사용자가 수정한 상단 영문 문구 삭제와 ‘카카오 부트캠프 AX 기술 동아리.’ 푸터를 유지했습니다.

## 로컬 검증

`npm run build` 후 새 로컬 DB에 `drizzle/0000_workable_iron_man.sql`, `0001_orange_onslaught.sql`, `0002_previous_joystick.sql`을 파일명 순으로 한 번씩 적용합니다. 이미 적용한 마이그레이션은 재실행하지 않습니다.

```sh
node --import ./scripts/sites-env.mjs ./node_modules/wrangler/bin/wrangler.js d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/0002_previous_joystick.sql
npm run dev -- --port 5174
node tests/matching.mjs http://127.0.0.1:5174
npx tsc --noEmit
```

테스트는 localhost에서만 실행되며 동시 10명 매칭, 부서 분리, 중복 배정 방지, 일별 건수 중복 방지, 명단 검증, 이동·대기 선택 동기화 및 동시 선택, 재매칭 초기화, 취소·완료, 개인정보 분리, 세션·출처 검증을 확인합니다. Node.js 22에서 `.ts` 가져오기가 지원되지 않는 경우 `node --experimental-strip-types tests/matching.mjs`를 사용합니다.
