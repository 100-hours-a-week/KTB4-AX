# Clear Message

### 받은 말은 빠르게. 보낼 말은 명확하게.

복잡한 협업 메시지에서 맥락과 요청을 찾고, 두서없는 초안을 전달하기 좋은 순서로 정리합니다.

v0.1.1 · 두 가지 스킬 · 원문 붙여 넣기 · 별도 API 키·서버 없음

[사용법](#사용법) · [출력 예시](#출력-예시) · [설치](#설치) · [검증](#검증과-피드백)

</div>

## 사용법

| 지금 필요한 것 | 스킬 | 받는 결과 |
| --- | --- | --- |
| 상대가 무슨 말을 했고, 내가 무엇에 대응해야 하는지 | `read-message` · 받은 말 이해하기 | **핵심 → 대응 여부 → 필요한 맥락** |
| 내가 하려는 말을 상대가 이해하기 쉬운 순서로 | `write-message` · 보낼 말 정리하기 | **바로 복사할 메시지 본문** |

스킬을 선택한 뒤 원문을 그대로 붙여 넣으세요. 긴 글과 짧은 보고 모두 사용할 수 있습니다.
단체 대화에는 `나는 민수`처럼 이름·역할을 덧붙이면 요청 대상을 구분하기 쉽습니다.

```text
$read-message
[상대에게 받은 메시지 원문]
```

```text
$write-message
[내가 보내려던 초안]
```

설치 환경에 따라 이름에 `clear-message:`가 붙을 수 있습니다. 스킬 선택기에 표시된 이름을 사용하세요.

## 출력 예시

### 읽기 — 핵심과 대응부터

> 캐시 PR은 올렸어요. 테스트는 아직 못 고쳤습니다. 민수님, 내일 오전까지 검토하고 의견 알려주실 수 있나요? TTL은 5분으로 제안했는데 아직 합의된 건 아니에요.

```text
핵심: 캐시 PR을 올렸으며 테스트 수정은 남아 있습니다. TTL 5분은 미합의 제안입니다.
대응: 답변 있음 · 작업 있음 — 민수님에게 PR 검토와 의견 회신을 부탁했습니다.

대응할 내용
- 민수님 · 검토 후 답변: 메시지 기준 내일 오전까지 PR을 검토하고 의견 알려주기.

상황
- 발신자는 테스트를 아직 수정하지 못했다고 보고했습니다.

제안·논의
- 캐시 TTL 5분 제안. 합의 여부는 미확정입니다.
```

짧은 보고에는 필요한 두 줄만 나옵니다.

```text
핵심: 발신자는 배포를 완료했고 헬스체크가 정상이라고 보고했습니다.
대응: 답변 없음 · 작업 없음 — 제공된 메시지에 요청은 없습니다.
```

`없음`은 원문에 요청이 없다는 뜻입니다. 요청이 애매하면 `불명확`, 부탁은 분명하지만 내용이 빠졌다면 `있음 — 내용 불명확`으로 표시합니다.
원문에 없는 작업은 배정하지 않으며, 취소되거나 답변이 끝난 요청은 현재 남은 요청과 구분합니다.

### 쓰기 — 전송할 본문부터

> 민수님한테 진행 공유예요. 지금 해주실 일은 없어요. 금요일까지 하겠다는 약속은 그대로고요. 테스트 하나가 실패해서 현재는 가능할 것 같다는 정도예요.

```text
민수님, 진행 상황 공유드려요. 지금 해주실 일은 없어요.

금요일까지 완료하겠다는 약속은 그대로예요. 다만 테스트 하나가 실패하고 있어,
현재로서는 가능할 것 같다는 단계예요.
```

요청은 앞쪽에, 판단에 필요한 배경은 그 뒤에 둡니다. 질문·보고·제안에 맞춰 순서를 조정하고 원래 말투와 확실성을 보존합니다.
기한·대상처럼 중요한 정보가 충돌하면 본문에 확인 표시를 남기고, 아래에 **보내기 전 확인**을 분리합니다.

## 설치

Codex CLI가 설치된 환경에서 저장소를 받아 플러그인을 설치합니다.

```bash
git clone https://github.com/100-hours-a-week/KTB4-AX.git
cd KTB4-AX/harry
codex plugin marketplace add .
codex plugin add clear-message@harry-ax
```

설치 후 새 대화의 스킬 선택기에서 두 스킬을 확인하세요. 별도 API 키나 외부 서비스 연결은 필요하지 않습니다.
설치 방식은 [OpenAI 공식 플러그인 문서](https://developers.openai.com/plugins/build/plugins)를 참고하세요.

<details>
<summary>플러그인 대신 두 스킬만 연결하기</summary>

`harry/` 디렉터리에서 실행합니다. 같은 이름의 파일·링크가 있으면 먼저 확인하고, 플러그인과 중복 설치하지 마세요.

```bash
mkdir -p ~/.codex/skills
ln -s "$PWD/clear-message/skills/read-message" ~/.codex/skills/read-message
ln -s "$PWD/clear-message/skills/write-message" ~/.codex/skills/write-message
```

</details>
