# 볼트 규칙

이 볼트는 하루 기록(일기)을 모으는 Obsidian 볼트다. daily-log 스킬로 일기를 쓰는 에이전트는 아래 규칙을 먼저 지킨다.

## R1. 사실 창작 금지
- 원본(화면 기록·GitHub·대화)에 없는 사실을 만들지 않는다.
- 추론한 내용은 본문에 `> [!question] 확인 필요` 콜아웃으로 표시한다.

## R2. 수치에는 근거
- 일기의 수치는 "시스템을 잰 값"만 쓴다(응답 시간·처리량·정확도·메모리·비용 등). 작업량(커밋·PR·줄 수·테스트 개수)은 수치가 아니다.
- 수치마다 어떻게 쟀는지와 출처를 함께 적는다. 상세는 daily-log 스킬의 `기록-작성기준.md` §4.

## R3. raw/ 는 읽기 전용
- `raw/` 아래 파일은 고치지 않는다. 예외는 `raw/일기/YYYY-MM-DD.md` 하나다.
- 일기의 `## 내 메모`는 사용자가 직접 쓴 글이므로 고치지 않는다.

## R4. 설치는 안내만
- 프로그램·패키지·CLI는 에이전트가 설치하지 않는다. 명령과 이유만 안내한다.

## R5. git은 안내만
- `git add`·`commit`·`push`는 에이전트가 실행하지 않는다. 일기에는 개인정보가 들어가므로 무엇을 올릴지는 사용자가 정한다. `git status` 조회는 괜찮다.
